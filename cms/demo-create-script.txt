The two JSON files have to be loaded up into cms_oversight.federal_claims.


1. The External FDA/CMS API (Python + FastAPI)

Run version 1. 


2. The Node.js Backend Service
Create a directory named backend/. This server connects to MongoDB Atlas, calls the Python API, and performs the $set update.

# Terminal 2: Setup Node Backend
mkdir backend && cd backend
npm init -y
npm install express mongodb dotenv cors axios

Then, see files in /backend


3. The Frontend UI (React + MongoDB LeafyGreen)
Using MongoDB's official React components (@leafygreen-ui) ensures your presentation looks directly branded by MongoDB.

# Terminal 3: Setup React Frontend
npx create-react-app frontend
cd frontend
npm install @leafygreen-ui/leafygreen-provider @leafygreen-ui/button @leafygreen-ui/card @leafygreen-ui/code @leafygreen-ui/typography cors

Then, see files in /frontend

  "build": "react-app-rewired build",
